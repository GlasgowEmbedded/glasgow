Installing & updating
=====================

There are two possible ways to install the Glasgow Interface Explorer toolchain:

.. toctree::
    :maxdepth: 1

    source
    binary

Installing from source is the most flexible option, and is recommended for users who are already familiar with Python and its package manager, or wish to work on the Glasgow software itself. This method is supported on Linux, Windows, macOS, and FreeBSD. It requires a few dependencies to be installed first.

Installing a binary package is the easiest and most reliable option for users who do not plan on modifying the Glasgow software itself. This method is supported only on Windows. The installer is completely self-contained and requires no network access.
